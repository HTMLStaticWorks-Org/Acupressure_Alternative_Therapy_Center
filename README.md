# Acupressure & Alternative Therapy Center — Website

## Files
- `index.html` — Classic homepage
- `home-2.html` — Premium wellness homepage
- `therapies.html` — Therapy descriptions and filters
- `conditions.html` — Concerns and safety guide
- `practitioners.html` — Practitioner standards and profile template
- `contact.html` — Appointment enquiry and map preview
- `styles.css`, `script.js` — Shared design system and interactions
- `assets/wellness-collage.png` — Generated wellness visual

## Run
Extract the ZIP and open `index.html` in a modern browser. Internet access is needed for Google Fonts and remote photography.

## Included interactions
- Light/dark theme toggle (persists in local storage)
- RTL/LTR direction toggle (persists in local storage)
- Responsive mobile navigation
- Therapy category filters
- Interactive educational meridian-point markers
- Client-side demo appointment and newsletter form validation/feedback
- Map preview and external map search

## Before production
- Replace the placeholder clinic address and map with the verified clinic location.
- Add real practitioner names, credentials, registrations and approved biographies.
- Add verified phone, email, fees, session durations and policies.
- Connect forms to a secure booking/newsletter backend; current forms are demos and do not transmit or store submissions.
- Have all health-related content reviewed by a qualified professional.
- Replace any sample or remote imagery as needed and confirm usage rights.
- The website does not diagnose, promise cures, or replace medical care.
